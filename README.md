# LeoNix Server (Spring Boot)

Spring Boot 3 backend application configured with Feature-Driven architecture.

## Requirements
- Java 17+
- Gradle 8+ or Maven 3.8+

## Running the application
Using Gradle:
```bash
./gradlew bootRun
```
Or Maven:
```bash
mvn spring-boot:run
```

The server starts on port `8080` by default.
